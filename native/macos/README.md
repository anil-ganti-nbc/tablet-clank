# Tablet Clank macOS field-test launcher

`build.sh` creates the canonical Finder app at `dist/Tablet Clank.app`. It forces loopback-only operation, binds to an OS-assigned ephemeral port, and stores every mutable artifact below `~/Library/Application Support/Tablet Clank/`. The dashboard is a stdlib-only `http.server` app (`webapp.py`) — no new runtime dependency was added to the `tablet_clank` package itself, which stays dashboard-free per its HANDOFF.md; this is a field-test-only layer bolted on for the packaged client. "Collect Now" runs exactly `tablet_clank.production.run_production`, the same bounded, locked, allowlist-only cycle already exercised from the CLI. Alerts remain disabled (`ALERTS_ENABLED = False`); no Discord/webhook destination exists in this codebase, and any such env vars are stripped defensively before import.
